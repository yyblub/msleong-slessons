# Ms Leong's Lessons

Interactive art resources for Ms Leong's students.

## Two versions

| | Claude (main) | GitHub Pages (copy) |
|---|---|---|
| Ms Leong's Lessons | https://claude.ai/artifact/294MDJeBwEpYdH1qC2k6Px | `index.html` |
| Elements & Principles Lab | https://claude.ai/artifact/ABQdE9vKFQV4rje99gcDh4 | `lab/` |
| Feedback Sandwich | https://claude.ai/artifact/MhUpyF11d8AtvkM2Pztx8U | `feedback-sandwich/` |

**The Claude pages are the main site.** Edit mode, uploading slides, and pasting Padlet rows from the sign-up sheet only work there, because those pages can save changes to themselves.

**The GitHub Pages copy is read-only.** Students can browse it, search the slides, open Padlets, use the Mystery Egg and timer, and use the lab and Feedback Sandwich. New slides and Padlets appear here only after the copy is updated from the Claude page.

## Folders

- `index.html`, `lab/`, `feedback-sandwich/`: the GitHub Pages site.
- `claude-source/`: exact backups of the three Claude pages as published.

## Updating the copy

Ask Claude to "update the GitHub copy of Ms Leong's Lessons". It reads the latest Claude pages, refreshes the files here, and pushes the change.

## Privacy

This repository and the Pages site are public. Padlet entries should use first names and class only.
